# Festival DAM 2027

Web estática de un festival ficticio de música que se celebrará los días **18 y 19 de junio de 2027**.

## Páginas

- `index.html`: presentación del festival.
- `programa.html`: programa de conciertos.
- `entradas.html`: información sobre las entradas.
- `style.css`: estilos comunes.
